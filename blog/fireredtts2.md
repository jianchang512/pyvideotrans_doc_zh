# FireRed-TTS2 小红书TTS2一键整合包

> 下载地址： https://pan.baidu.com/s/14i_l85eplfeXp0otfY_O0Q?pwd=zcwt


## 使用方法

1. 下载解压
2. 双击`双击启动.bat`
3. 第一次启动会下载 FireRed-TTS2 模型，模型总体积超过20G，用时可能较久，请耐心等待
4. 默认从`hf-mirror.com`镜像站下载模型，如果你能科学上网，希望从`huggingface.co`下载，请删除`pretrained_models`文件夹，并编辑`双击启动.bat`，删掉`set HF_ENDPOINT=https://hf-mirror.com`这行代码，然后重新启动


![0.png](https://img.pyvideotrans.com/file/1758170760549_0.png)


如果最终窗口底部显示如下图，说明成功.

![2.png](https://img.pyvideotrans.com/file/1758170779539_2.png)



如果最终出现`Error:` 如下图字样，则失败，请关闭窗口重新打开
![](https://pvtr2.pyvideotrans.com/1757555246399_3.png)




4. 成功后，将自动在浏览器中打开地址`http://127.0.0.1:7860`
