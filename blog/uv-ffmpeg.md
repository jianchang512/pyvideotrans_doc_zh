如果你经常玩 AI 项目，或者需要剪视频、提取音频，那么你一定要认识两个超实用的工具：

* 🎬 **ffmpeg**：音视频界的“瑞士军刀”，能剪辑、转码、提取字幕，应有尽有。
* 🧰 **uv**：管理 Python 环境的神器，让你一键运行各种 AI 项目，不用手动配置。

更棒的是，它们都可以**直接在 Windows 上使用**，只需下载 `.exe` 文件，解压即用，**不用安装、不污染系统**。
几分钟搞定，让你的电脑立刻变身 AI 实验平台！

---

## 🧩 第一步：安装 uv（Python 环境管理神器）

**uv** 是一个超快、超轻量的 Python 包管理工具。
简单说，它能自动帮你下载、安装并运行 AI 项目需要的所有库——
再也不用自己先是安装python，再创建虚拟环境，然后一个个 `pip install` ，还可能遇到大堆的模块冲突错误！

### ✅ Windows 安装步骤

1. **下载 uv**

   👉 点击下方链接，下载 Windows 版压缩包：

   ```
   https://github.com/astral-sh/uv/releases/download/0.9.8/uv-x86_64-pc-windows-msvc.zip
   ```

2. **解压文件**

   下载后解压，会看到一个文件夹，里面包含 `uv.exe` 及另外两个 `.exe` 文件。

3. **打开系统的专用目录**

   为了让电脑在任意位置都能识别 `uv` 命令，我们要把这些文件放进一个特定路径。

   * 打开任意文件夹（例如“此电脑”或“文档”）
   * 点击顶部的**地址栏**，输入：

     ```
     %userprofile%
     ```

     然后按 **回车**，会自动转到用户家目录。

4. **复制 uv 文件到该目录**

   把刚才解压的 `uv.exe` 以及同目录下的其他 `.exe` 文件，全部复制到这个文件夹中。

   接着打开cmd终端，如果尚未打开过，则按 windows键+r键，输入`cmd`确定，然后粘贴命令 **`reg add "HKCU\Environment" /v Path /t REG_EXPAND_SZ /d "%PATH%;%USERPROFILE%" /f`** 回车执行即可。

   ✅ 这样做的好处是：你可以在任意命令行窗口中直接输入 `uv` 使用，不用再输入复杂路径！

### 🍎 macOS 用户安装方式

如果你使用 macOS，安装更简单，只需在“终端 (Terminal)”中输入：

```bash
wget -qO- https://astral.sh/uv/install.sh | sh
```

## 🎬 第二步：安装 ffmpeg（音视频处理瑞士军刀）

**ffmpeg** 是所有视频工作者和 AI 爱好者的必备神器。
它能完成几乎所有音视频任务：剪辑、提取音轨、格式转换、合并、加字幕……样样精通！

### ✅ Windows 安装步骤

1. **下载 ffmpeg**

   点击以下链接获取完整版 Windows 构建包：

   ```
   https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-full.7z
   ```

2. **解压文件**

   下载后解压，会看到一个类似 `ffmpeg-x.x.x-full_build` 的文件夹（版本号可能不同）。

3. **找到关键文件**

   打开该文件夹 → 进入其中的 `bin` 子文件夹，里面有：

   * `ffmpeg.exe`
   * `ffprobe.exe`（查询音视频信息）
   * `ffplay.exe`（简单播放器）

   💡 这三个文件建议一起复制，方便以后使用。

4. **将他们和uv放一起**

   把上面这三个 `.exe` 文件复制到 **与 uv 相同的目录**：

   ```
   %userprofile%\.local\bin
   ```

   这样你在任意命令行窗口中输入 `ffmpeg`，就能直接使用啦！

---

### 🍎 macOS 用户安装方式

macOS 用户可直接在终端执行以下命令：

```bash
brew install ffmpeg
```

---

## %userprofile%\.local\bin 不在环境变量中，怎么办？
点开左下角“开始菜单”找到 "命令行提示符"，右键-->更多--->以管理员身份运行，粘贴这个命令，回车执行

reg add "HKCU\Environment" /v Path /t REG_EXPAND_SZ /d "%PATH%;%USERPROFILE%\.local\bin" /f

## 🎉 完成啦！你已经成功配置好 uv 和 ffmpeg！

👏 恭喜！到这里，两个强大的工具都安装好了。
只需这一次设置，以后就能在任意目录下直接使用它们。

从现在开始：

* 需要处理视频？打开命令提示符 (CMD) 输入：

  ```bash
  ffmpeg -i 输入.mp4 -ss 00:00:10 -t 5 输出.mp4
  ```

  （上例表示剪出从第10秒开始的5秒片段）

* 运行 Python AI 项目？直接输入：

  ```bash
  uv run 脚本.py
  ```

是不是很简单？
无论你是视频剪辑小能手，还是 AI 玩家乐新手，这两个工具都能让你事半功倍。

| 工具         | 作用              | 安装方式                             |
| ---------- | --------------- | -------------------------------- |
| **uv**     | 管理 Python 环境与依赖 | 解压后放入 `%userprofile%\.local\bin` |
| **ffmpeg** | 处理音视频文件         | 解压后放入同一目录                        |

💡 以后若不再需要，直接删除这些 `.exe` 文件即可，系统不会留下任何痕迹。
轻量、干净、好用，这就是它们的魅力！
